# Assignment 4 - Forms and Validation

This project was created for the Front-End Development course.

The main goal of this assignment is to practice creating HTML forms, using HTML5 validation, styling forms with Bootstrap, and applying Bootstrap validation feedback.

## Tasks

### Task 0 - Simple Contact Form
A basic contact form with:
- Name
- Email
- Message
- Submit button

### Task 1 - HTML5 Validation
The contact form includes HTML5 validation attributes such as:
- required
- type="email"
- maxlength
- minlength

### Task 2 - Bootstrap Form
The contact form is styled using Bootstrap components and Bootstrap Grid.

### Task 3 - Bootstrap Validation
Bootstrap validation classes are used to show valid and invalid feedback messages.

### Task 4 - Registration Form
The registration form includes:
- First Name
- Last Name
- Email
- Password
- Confirm Password
- Gender
- Hobbies
- Country
- Register button
- Reset button

The form also includes HTML5 and Bootstrap validation.

## Technologies Used

- HTML5
- CSS
- Bootstrap 5
- JavaScript

## Navigation

The project contains a navigation bar that allows users to move between all assignment tasks.

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Use the navigation bar to open other tasks.
